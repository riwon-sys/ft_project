# DevConnect

**Spring Boot · React(Admin Web) · Flutter(App) 기반 팀 협업 프로젝트**  
관리자(Admin) 전용 React 웹을 독립적으로 설계·구현했습니다.  
기존 백엔드를 수정하지 않고 DTO/Entity를 분석하여 필요한 기능만 추출·호환하며,  
팀의 흐름을 해치지 않는 구조로 독립 기능을 제공했습니다.  

---

## 📌 프로젝트 개요
- **제작기간**: 2025-04-14 ~ 2025-05-11  
- **핵심 목표**: 기존 백엔드 무변경 원칙을 지키며 Admin 전용 웹 독립 구현  
- **역할**:  
  - Admin 전용 화면 개발(목록/상세/수정/삭제)  
  - JWT 연동 및 라우팅 보호  
  - API 응답 포맷 변환(프론트 어댑터 계층)  
- **협업 방식**: 변경 최소화 전략, PR/리뷰 기반 충돌 방지, 문서화 정비  

---

## 🔑 기술 스택
- **Backend**: Spring Boot, REST API (기존 백엔드 활용)  
- **Frontend**: React (Vite, Joy UI, Recharts), JWT 인증, 보호 라우팅(RoleRoute)  
- **Mobile**: Flutter (App)  
- **Etc.**: DTO/Entity 분석, API 호환 설계, 독립 배포  

---

## ⚙️ 주요 기능
- **Admin 전용 기능**  
  - 기업·개발자·프로젝트·평가 목록/상세/수정/삭제  
- **JWT 인증 & 라우팅 보호**  
  - PrivateRoute + RoleRoute 기반 접근 제어  
- **API 호환 계층**  
  - DTO 매핑 계층(어댑터)으로 백엔드 무변경 원칙 준수  
- **통계/대시보드**  
  - Joy UI + Recharts 기반 통계 시각화  

---

## 🛠️ 트러블슈팅 사례
- **응답 포맷 불일치**  
  - 원인: 기존 백엔드 응답 포맷과 Admin Web 요구 포맷 차이  
  - 해결: DTO 매핑 계층(어댑터) 도입  
  - 결과: 백엔드 무변경 원칙 유지 + 프론트 요구 충족  

- **권한 분기 누락**  
  - 원인: 일부 화면 직접 접근 가능  
  - 해결: JWT 검증 + RoleRoute 재정립  
  - 결과: 권한 없는 접근 차단, 보안 정책 강화
